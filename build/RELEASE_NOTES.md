CEsim Studio 1.40.0 gives the app its new look: a new logo and an orange colour across the whole interface.

## Downloads

| System | File |
|---|---|
| macOS (Apple Silicon) | `CEsim-Studio-1.40.0-arm64.dmg` |

| Windows 10 and 11 (64-bit) | `CEsim-Studio-1.40.0-Windows-x64-Setup.exe` (installer) or `CEsim-Studio-1.40.0-Windows-x64-Portable.zip` |

## New

- **New logo:** the letters C and E drawn as circuit traces with a node at each end, on an orange square. It is the app icon on macOS, Windows (installer, taskbar, Start menu and Microsoft Store tiles), Linux and the web version on the iPad home screen, and it sits at the top of every tool.
- **Orange interface:** buttons, selected items, tool tiles and highlights in the Studio and in every tool are orange. The Circuit tool's Light and Dark themes follow it (Blueprint and Graphite keep their own colours).
- **Start screen:** a dark warm start screen with the new logo.
- **Theme and colours:** orange is the default colour. Blue is still in the list for anyone who prefers it, and a colour you chose yourself stays as it is.

## First launch

- **macOS:** choose the arm64 file for Apple Silicon (M1 and later) and the Intel-x64 file for Intel Macs. Right-click the app, choose Open, then Open again. If macOS says the app is damaged, run `xattr -cr "/Applications/CEsim Studio.app"` once in Terminal.
- **Windows:** if SmartScreen appears, choose More info, then Run anyway. The installer does not need administrator rights.
- **Linux:** make the AppImage executable with `chmod +x CEsim-Studio-1.40.0-Linux-x86_64.AppImage` and run it, or install the package with `sudo apt install ./CEsim-Studio-1.40.0-Linux-amd64.deb`.
