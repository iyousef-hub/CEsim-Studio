## CEsim Studio 1.4.0

Circuit simulator, diagrams and 3D in one app. BY. YOUSEF

### Downloads
| System | File |
|---|---|
| macOS (Apple Silicon) | `CEsim-Studio-1.4.0-arm64.dmg` |
| Windows 10/11 (64-bit) | `CEsim-Studio-1.4.0-Windows-x64-Setup.exe` (installer) · `CEsim-Studio-1.4.0-Windows-x64-Portable.zip` |
| Linux (64-bit) | `CEsim-Studio-1.4.0-Linux-x86_64.AppImage` · `CEsim-Studio-1.4.0-Linux-amd64.deb` |

### New in 1.4.0
- **Circuit from image:** turn a photo or screenshot of a schematic into an editable circuit with a vision model that runs on your computer (Ollama). Nothing is uploaded.
- **Studio themes:** Light, Paper, Gray, Dark and Night, with eight accent colours and a custom colour.
- Windows and Linux builds.

### Also in the 1.3 series
- Circuit: text notes, net labels, title block, draggable part labels, colour palette, export to PNG / JPG / WebP / SVG / PDF, BOM and node-voltage CSV, screenshot to clipboard. Clearer meter displays with exact readings. Parts dropped on a wire connect automatically.
- Diagram: floating action bar, Tab to add a connected shape, recent shapes, minimap, find (Ctrl+F), shortcuts (F1), insert image, WebP and visible-area export.
- 3D: control settings (zoom / rotate / pan speed, invert zoom, mouse buttons, rotation snap, grid, background), JPG / WebP / SVG export and a CSV size report.

### First launch
- **macOS:** right-click the app → **Open** → **Open**. If it says the app is damaged: `xattr -cr "/Applications/CEsim Studio.app"`.
- **Windows:** if SmartScreen appears, choose **More info** → **Run anyway**.
- **Linux:** `chmod +x CEsim-Studio-1.4.0-Linux-x86_64.AppImage` then run it, or `sudo apt install ./CEsim-Studio-1.4.0-Linux-amd64.deb`.
