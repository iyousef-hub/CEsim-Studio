## Connect shapes faster

- Hover any shape and four blue arrows appear around it.
- Click an arrow to add a connected copy in that direction, placed clear of other shapes.
- Hover an arrow to choose a different shape for the next step.
- Shift+click an arrow to connect to the next shape in that direction, or drag an arrow to connect anywhere.
- The new connector takes the line colour and width of the first shape.

## A new right panel

- **Style:** six pages of preset styles, solid or gradient fill, line colour, width and pattern, opacity, rounded corners, sketch, glass and shadow, depth for 3D shapes, copy and paste style, set as default style, edit every property, and change one shape into another.
- **Text:** font family, size, bold, italic and underline, alignment, position inside or around the shape, writing direction (automatic, left to right, right to left), font colour, label background and border, text shadow, word wrap, automatic font size and spacing on each side.
- **Arrange:** size and position, rotate 90°, flip, keep proportions, lock, order, align, distribute, group, and save as my shape.
- **Connectors:** colour, width, pattern, opacity, elbow, straight or curved, arrow ends, reverse direction, and a flowing animation.

## 367 shapes in 21 groups

New groups: Basic, Arrows, 3D, Neural networks, Data structures, Charts and infographics, Icons, BPMN, Control and signals, Math and geometry and My shapes. Electrical, UML and Network have more shapes. Charts, arrays, stacks, queues and matrices take their values from the text you type.

## Sketch page

- A page for free drawing on lined, squared, dotted or blank paper, with a pen, a marker and an eraser, eight colours and four widths.
- A wobbly line becomes straight and snaps to level, vertical or 45°.
- A stroke with a head becomes an arrow. Loops become circles, ellipses, rectangles, triangles or diamonds.
- Holding still at the end of a stroke straightens it into clean segments.

## Shape maker

- Draw a new shape point by point or freehand, or start from a square, triangle, star, arrow, house, blob or gear.
- Smooth the outline into curves, or extrude it into a 3D solid.
- Saved shapes appear under My shapes and are stored in the diagram file, so they open on other computers.
- Any selection can also be saved as one shape.

## Neural network framework

- **Neurons:** layers of any size, input and output names, activations, bias neurons, connections coloured by the sign and thickness of each weight, left-to-right or top-to-bottom. Large layers are shortened with ⋮.
- **Layer blocks:** one line per layer (convolution, pooling, flatten, dense, dropout, batch norm, LSTM, GRU, embedding, attention, transformer, softmax), with ready CNN, RNN, transformer and MLP examples.
- **Train and show:** trains a small network on a circle, exclusive-or, two-cluster or spiral problem. Each neuron shows its output over the plane, the lines show the weights, and the output shows the data and the test and training loss. Features, hidden layers, activation, learning rate, epochs and noise can all be changed.
- Select a drawn network to change its settings and draw it again, or keep it as plain shapes.

## Export and present

- New formats: HTML (all pages, with zoom), JSON, animated SVG with flowing connectors, and print.
- **Present** shows the pages full screen; the arrow keys move between pages.

## First launch

- **macOS:** right-click the app, choose Open, then Open again. If macOS says the app is damaged, run `xattr -cr "/Applications/CEsim Studio.app"` once in Terminal.
- **Windows:** if SmartScreen appears, choose More info, then Run anyway. The installer does not need administrator rights.
- **Linux:** make the AppImage executable with `chmod +x CEsim-Studio-1.6.0-Linux-x86_64.AppImage` and run it, or install the package with `sudo apt install ./CEsim-Studio-1.6.0-Linux-amd64.deb`.
